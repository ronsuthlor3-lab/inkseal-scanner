# Inkseal Scanner

[English](README.md)

ส่วนขยายเบราว์เซอร์สำหรับ Chrome และ Edge ที่ช่วยหารูปซึ่งมี **รหัสผู้สร้าง Inkseal แบบล่องหนของคุณ** ระหว่างท่องเว็บ
เป็นเครื่องมือคู่กับ [Inkseal](https://ronsuthlor3-lab.github.io/inkseal/) เครื่องมือฟรีสำหรับประทับตราผลงานด้วยลายมือ
ลายเซ็นดิจิทัล Ed25519 และลายน้ำล่องหน

**ทุกอย่างทำงานในเครื่องของคุณ** ส่วนขยายไม่รายงาน ไม่อัปโหลด และไม่ส่งข้อมูลไปที่ใดเลย ไม่มีระบบเก็บสถิติ และไม่โหลดโค้ดจากภายนอก

## ทำอะไรได้บ้าง

- **เฝ้าดูรหัสผู้สร้างของคุณ** ใส่รหัสได้หลายรหัสในหน้าตั้งค่า (รูปแบบ `XXXX-XXXX-XXXX` ดูได้ในแท็บ "ตัวตน" ของเว็บ Inkseal)
- **สแกนรูประหว่างท่องเว็บ** ตรวจรูปขนาดอย่างน้อย 128×128 พิกเซลเมื่อเลื่อนมาบนจอ (ไม่เกิน 150 รูปต่อหน้า ทีละไม่กี่รูป ไม่ตรวจ URL เดิมซ้ำ)
- **แจ้งเมื่อพบ** ขึ้นตัวเลขบนไอคอน ป้ายเล็ก ๆ บนรูป ("Inkseal: ผลงานของคุณ" พร้อมรหัส) และบันทึกในรายการของ popup (หน้าเว็บ ที่อยู่รูป เวลา)
- **"ตรวจด้วย Inkseal" ที่รูปใดก็ได้** คลิกขวาที่รูปเพื่อดูผู้สร้าง ชื่อผลงาน สถานะตรา (ถูกต้อง / ถูกแก้ไข / ปลอม / ไม่มี) รหัสล่องหน และคำเตือนเมื่อรหัสไม่ตรงกัน ใช้กฎเดียวกับแท็บ "ตรวจสอบ" ของเว็บ
- หน้าจอภาษาไทยและอังกฤษ

## ติดตั้ง (แบบ unpacked)

ยังไม่ได้อยู่ใน Chrome Web Store / Edge Add-ons

1. ดาวน์โหลด repo นี้ (ปุ่มสีเขียว **Code** → **Download ZIP**) แล้วแตกไฟล์ หรือใช้ `git clone`
2. เปิด `chrome://extensions` (Chrome) หรือ `edge://extensions` (Edge)
3. เปิด **Developer mode**
4. กด **Load unpacked** แล้วเลือกโฟลเดอร์ **`extension`** ที่อยู่ใน repo
5. คลิกไอคอน Inkseal (ปักหมุดได้จากเมนูรูปจิ๊กซอว์) → **ตั้งค่ารหัสผู้สร้าง**

ต้องใช้ Chrome หรือ Edge รุ่น 116 ขึ้นไป การยืนยันลายเซ็น Ed25519 ต้องใช้รุ่น 137 ขึ้นไป ถ้ารุ่นเก่ากว่านั้น
ส่วนขยายจะบอกว่า "ตรวจไม่ได้" แทนการบอกว่าลายเซ็นปลอม ส่วนรหัสล่องหนใช้ได้ทุกรุ่นที่รองรับ

## สิทธิ์ที่ขอ และเหตุผล

| สิทธิ์ | ใช้ทำอะไร |
| --- | --- |
| `storage` | เก็บรหัสที่เฝ้าดู สวิตช์เปิด/ปิด ภาษา และรายการรูปที่พบ ไว้ในเครื่องของคุณ |
| `contextMenus` | เพิ่มเมนู "ตรวจด้วย Inkseal" เมื่อคลิกขวาที่รูป |
| เข้าถึงทุกเว็บไซต์ (`<all_urls>`) | สคริปต์ต้องทำงานบนหน้าที่คุณเปิดเพื่อมองเห็นรูป และ service worker ต้องดาวน์โหลดรูปเองเพื่ออ่านพิกเซล (canvas ของหน้าเว็บจะถูก CORS บล็อก) การดาวน์โหลด **ไม่ส่งคุกกี้** และมักใช้สำเนาจากแคชของเบราว์เซอร์ |

ไม่ได้ขอ: `tabs`, `history`, `webRequest`, `notifications`, `downloads`, `scripting` ไม่ติดต่อเซิร์ฟเวอร์ใดนอกจากเว็บที่เก็บรูปซึ่งคุณกำลังดูอยู่แล้ว

ถ้าต้องการตรวจเฉพาะตอนคลิกขวา ให้ปิด **สแกนหน้าเว็บ** ใน popup สคริปต์บนหน้าเว็บจะไม่ทำอะไรเลย

## ข้อจำกัด (พูดกันตรง ๆ)

- **รูปที่ถูกย่อ ตัด หมุน หรือบีบอัดใหม่ มักทำให้รหัสล่องหนหายไป** โซเชียลมีเดียส่วนใหญ่ย่อและบีบอัดรูปที่อัปโหลด
  สำเนาที่ถูกโพสต์ซ้ำบนแพลตฟอร์มเหล่านั้นจึงมักตรวจไม่พบ (ชุดทดสอบใน repo นี้ยืนยันว่ารูปที่ย่อเหลือ 50% รหัสหายไป)
- เว็บไซต์มักแสดงรูปย่อ ส่วนขยายตรวจเฉพาะไฟล์ที่หน้าเว็บโหลดมาจริง ไม่ใช่ไฟล์ต้นฉบับ
- รูปที่ต้องล็อกอินจึงดูได้ (เพราะไม่ส่งคุกกี้) รูปแบบ `blob:` และรูปที่ใหญ่เกิน 25 MB / 36 ล้านพิกเซล จะไม่ถูกตรวจ
- **"ไม่พบ" ไม่ได้แปลว่ารูปนั้นไม่ใช่ของคุณ** และ **"พบ" ก็ไม่ได้แปลว่ามีการละเมิด** อาจเป็นสำเนาที่ได้รับอนุญาตหรือคุณแชร์เอง
  ให้ถือว่าเป็นเบาะแสเพื่อตรวจสอบต่อ ไม่ใช่หลักฐานในตัวเอง
- รหัสล่องหนมี 48 บิตพร้อม CRC-16 โอกาสจับคู่ผิดกับรูปทั่วไปต่ำมาก แต่ไม่ใช่ศูนย์
- หน้าเว็บอาจทำให้รูปดูต่างจากไฟล์จริง (CSS filter, canvas) ส่วนขยายอ่านจากไฟล์
